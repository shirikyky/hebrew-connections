# חיבורים 🧩

משחק מילים יומי בעברית — מיינו 16 מילים ל-4 קבוצות של 4.

## מה זה?

בכל יום חידה חדשה: על הלוח 16 מילים, ועליכם לחלק אותן ל-4 קטגוריות
של 4 מילים כל אחת. מותרות רק 4 טעויות. בדומה ל-Connections של הניו יורק
טיימס — אבל בעברית.

## איך מריצים

פותחים את `index.html` בדפדפן. אין תלות חיצונית, אין build.

## בדיקות

```bash
npm test
```

## טכנולוגיה

HTML, CSS ו-JavaScript נקי בלבד (ES Modules), ללא ספריות.

- `data/puzzles.js` — רשימת החידות (4 קטגוריות × 4 מילים כל אחת)
- `src/game.js` — לוגיקת המשחק (טהורה, ניתנת לבדיקה)
- `src/app.js` — הממשק
- `index.html`, `styles.css` — הממשק והעיצוב

## תהליך עבודה

ענף פיתוח → Pull Request → CI (בדיקות) → מיזוג ל-`main`.
